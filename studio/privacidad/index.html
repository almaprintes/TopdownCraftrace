PRIVACIDAD
Y DATOS.

Esta página explica de forma resumida cómo funciona el registro común de CraftRace Studio en las webs de Top Down RACE y SlotRace. Es información técnica del servicio, no sustituye los textos legales exigibles para la publicación comercial.

QUÉ DATOS SE UTILIZAN

Para el acceso a CraftRace Studio se utiliza Supabase Auth. Según el método elegido, el servicio gestiona un identificador de usuario, dirección de correo electrónico y los datos de autenticación necesarios para iniciar sesión con Google, Apple o correo. El nombre público CraftRace Studio se conserva en una tabla separada. Nunca solicitamos contraseñas de Google ni Apple en nuestra web.

UNA CUENTA, JUEGOS SEPARADOS

La cuenta permanente se identifica con el mismo ID de Supabase en ambos juegos. Top Down RACE mantiene sus datos de partida y SlotRace sus circuitos y estadísticas por separado. Iniciar sesión en esta web no sube, fusiona ni sobrescribe automáticamente las partidas locales.

ALMACENAMIENTO EN EL DISPOSITIVO

La autenticación puede utilizar almacenamiento local del navegador para conservar la sesión. Los juegos también almacenan información de partida localmente. Borrar los datos del navegador podría eliminar circuitos de SlotRace que todavía no se hayan exportado o respaldado.

GOOGLE Y APPLE

Al acceder con Google o Apple se inicia el proceso de autenticación del proveedor correspondiente. Vincular los dos métodos al mismo usuario requiere una sesión existente y confirmación de identidad; no basta compartir un nombre de perfil.

SOPORTE Y CONTROL DE TU CUENTA

Puedes cerrar tu sesión desde Mi cuenta. Las funciones de sincronización completa, portabilidad y eliminación desde la propia web están en desarrollo; no las presentaremos como existentes hasta implementarlas y probarlas.
