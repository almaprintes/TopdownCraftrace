# Promoción BETA 1.1.171

La rama `beta-1.0` adopta el estado aprobado de `main` DEV 1.1.171 y cambia
únicamente su identidad visible a `BETA 1.1.171`.

La candidata conserva:

- el juego, progresión y almacenamiento existentes;
- los perfiles de Spark, Gripline y Vortex;
- la capa optimizada de Circuito Atlántico bajo su identidad canónica;
- los seis placements rewarded con validación estricta;
- Race Control, Supabase y Shipaton Judges Mode autorizado por backend.

Para Android se debe usar exclusivamente `BASE=./ npm run build:prod`. Ese
artefacto excluye Admin Hub, editores, herramientas internas y `public/tool`,
pero mantiene Judge Mode y los sistemas públicos. El wrapper local conserva
`com.craftracestudio.topdownrace`, la misma keystore de subida y el mismo
almacenamiento de la beta anterior.
